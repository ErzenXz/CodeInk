# Code of Conduct

CodeInk aims to be a useful place to build and discuss open source software. Be respectful and constructive in issues, pull requests, reviews, and other project spaces.

## Expected behavior

- Give feedback about work and ideas without personal attacks.
- Make room for people with different levels of experience and different backgrounds.
- Share enough context to help others reproduce a problem or understand a proposal.
- Respect privacy. Do not post someone else's personal information or private project material.

Harassment, discriminatory language, threats, sexualized attention, and repeated disruption are not acceptable. Maintainers may edit or remove content, close discussions, or limit participation to protect the community. Decisions should be proportionate to the behavior and explained when practical.

Use GitHub's **Report content** action for abusive content in the repository. If a report contains sensitive information, do not post it in a public issue. See [SECURITY.md](SECURITY.md) for vulnerability reports; security reporting is not a substitute for reporting personal conduct concerns.

This policy applies to CodeInk project spaces and to conduct representing the project elsewhere.
