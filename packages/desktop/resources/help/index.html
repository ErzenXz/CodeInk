CodeInk

Your desktop workspace for independently installed coding agents.

Get started

  1. Install and sign in to your preferred agent using its own CLI.
  2. In CodeInk, add a project folder and create a session.
  3. Choose an installed agent and one of its models in the composer, then send a prompt.

Configure an agent

Open Settings → Agents → Configure agents. Enter a command available on your PATH or an absolute executable path. Custom executables must support one of the listed protocols. CodeInk does not bundle or install agents or store their login credentials.

Appearance

Use Settings → General to choose a light or dark color scheme, theme, and fonts. CodeInk and CodeInk Classic are the built-in default themes.

Troubleshooting

If an agent is unavailable, verify its executable path and confirm that it works in your terminal. Authentication stays with that agent. For an expired Claude Code login, run claude auth login in your terminal and retry your message.

Use Help → Export Debug Logs to collect diagnostics locally. Review those files before sharing them with the person maintaining your CodeInk installation.

Supported connections

Codex uses app-server; Claude Code uses stream JSON; OpenCode uses its local HTTP server; Pi uses RPC. ACP connects Gemini CLI, Copilot, Cursor, Cline, Kimi, Qwen, Goose, Vibe, Droid, Devin, and more. Agents must be installed separately with ACP support. Start a new session to select a different agent; models can change between turns.

Text, streaming, approvals, session resume, files, and terminals are supported. Some engine-specific features, including fork/revert/compaction, rich attachments, and cloud sharing, are not yet translated across agents.
