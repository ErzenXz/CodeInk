# CodeInk Desktop

The CodeInk desktop application connects local coding agents and includes CodeInk Agent.

See the [repository README](../../README.md) for setup, protocol support, build instructions, and current limitations. The desktop UI lives in `../app` and uses components in `../ui` and `../session-ui`.

```sh
bun dev
bun typecheck
bun run test
bun run build
bun run package
```
