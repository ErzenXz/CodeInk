## Fixes found during this audit

- A hardcoded `4096` fixture server identity made direct session routes blank when tests used an isolated backend port. `session-timeline.fixture.ts` now uses the configured test port.
- Sidebar draft rows had been excluded even though the New Chat flows and existing tests require them. The exclusion was removed; pagination assertions now count real session rows separately from drafts.
- The Agent popup was dismissed by New Chat composer focus before its drawer entered the viewport. Its trigger and scoped focus-dismiss setting now keep the drawer usable; the close path dismisses the promotional card.
- The usage consent text now discloses the installed OpenUsage command-line fallback. Usage cards hide expired or explicitly stale limit windows and metrics using the desktop freshness fields.
- Non-English app and UI dictionaries now inherit **only** explicit pending-translation key lists (`app/src/i18n/locale-fallback.ts`, `ui/src/i18n/locale-fallback.ts`). New missing keys still fail parity. Four positional native dictionaries now use a fixed original-key list, preserving alignment across five inserted updater keys, the new tray keys, and future additions. Product-facing menu/recovery references in those four arrays say CodeInk; external OpenCode CLI references remain. Bun's `pa-PK` likely-subtag difference is normalized. A regression checks Croatian updater/menu alignment.
