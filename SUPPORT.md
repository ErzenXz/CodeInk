# Getting help

Start with the [FAQ](https://www.getcode.ink/faq.html), [agent setup guide](AGENT-SOURCES.md), and [download page](https://www.getcode.ink/download.html). The download page links to release notes and checksums for each channel.

For a reproducible bug or feature request, use a [GitHub issue](https://github.com/ErzenXz/CodeInk/issues/new/choose). Include your CodeInk version and channel, operating system, agent and CLI version, and the steps needed to reproduce the problem. You can find desktop logs through the app's debug-log export, but review them before attaching: they may contain project paths and diagnostic information. Remove credentials and private source content.

CodeInk does not administer agent accounts or model plans. For authentication, billing, model availability, or service outages, use the selected agent's own support channel. For a suspected CodeInk security vulnerability, follow [SECURITY.md](SECURITY.md) and avoid a public issue.
